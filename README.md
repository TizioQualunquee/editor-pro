# Minimal Text Editor

A professional, minimal text editor web app built with vanilla HTML, CSS, and JavaScript.

## Features

*   **Editorial Minimalism**: Distraction-free interface with a warm neutral gray palette.
*   **Live Statistics**: Real-time word, character, line, and paragraph counts.
*   **Text Tools**: Uppercase, lowercase, capitalize, and trim spaces.
*   **Sorting**: Sort lines alphabetically (ascending/descending).
*   **Search & Replace**: Find and replace text with optional Regular Expression support.
*   **No Backend**: Runs entirely in the browser.

## Usage

Simply open `index.html` in your web browser.

## Structure

*   `index.html`: The main structure of the application.
*   `style.css`: Styling rules following the "editorial minimalism" design.
*   `script.js`: Application logic for menus, stats, and text processing.
